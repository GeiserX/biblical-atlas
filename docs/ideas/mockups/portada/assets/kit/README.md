# El tema, copiado para los prototipos

Copia del tema del sitio para que los prototipos de la portada se vean igual aunque se sirva solo `docs/ideas/mockups/portada/`, sin `site/` al lado.

| Fichero | De dónde sale |
| --- | --- |
| `tokens.css`, `components.css` | `site/kit/`, sin cambios |
| `fonts.css` | `site/kit/fonts.css`, solo las dos caras que usan los prototipos (EB Garamond e Inter, latín, redonda) |
| `fonts/*.woff2`, `fonts/OFL-*.txt` | `site/kit/fonts/`, con su licencia SIL Open Font License 1.1 |
| `reunion.css` | los colores del modo reunión de `site/css/estudio.css` |
| `favicon.svg` | `site/favicon.svg` |

Si el tema del sitio cambia, se vuelve a copiar. El sitio de detrás no usa esta copia: carga la suya.
