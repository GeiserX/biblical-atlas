Al pulsar una marca se selecciona y su ficha dice qué es. La escala y la vista no se mueven. El cursor da el paso más corto para quedar dentro de las fechas de la marca; si ya estaba dentro, no se mueve.Al tocar una marca se elige; la escala y la vista no se mueven.

Cómo se usa

Arriba, toda la historia en una franja fija con una ventana: arrástrala o pulsa otra época para ir allí, y estira sus bordes para cambiar la escala.

Abajo, esa ventana en detalle con el nombre entero de cada cosa: arrastra para moverte, pulsa una marca para verla y usa la rueda con Ctrl, el pellizco o las escalas para acercarte. Un grupo «+N» abre su lista en la ficha; «Ir a» lleva el cursor a una fecha escrita.
